- 根 `CMakeLists.txt`：`find_package(QT NAMES Qt6 Qt5 ... Core Widgets Svg)`，
  Qt6 ≥ 6.5.0 / Qt5 ≥ 5.15.2 硬校验，源码侧与安装包 consumer 侧都校验。
- 默认静态库；`BUILD_SHARED_LIBS=ON` 走动态库。导出宏 `QT_MD3_EXPORT` 已按
  静态/动态分别接好（静态时 PUBLIC 定义 `QT_MD3_STATIC`）。
- 可安装：头文件 + `qt-md3-targets` 导出 + `qt-md3Config.cmake`，
  支持 `find_package(qt-md3 CONFIG REQUIRED)`；Windows 可选 `windeployqt`。

- `TestMd3Version`：QTest 冒烟，校验语义化版本。
- `TestMd3NoQss`：扫描 `src/ examples/ tests/ resources/`，禁止任何 QSS。
- `TestMd3CoveragePolicy`：解析 `docs/md3-coverage.md`，校验 36 族齐全、
  每行 9 列；阶段一未全绿时若 `src/widgets/` 出现阶段二公开组件则失败。
