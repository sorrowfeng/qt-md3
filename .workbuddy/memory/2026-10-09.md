**Qt 坑（新）**：
- **Qt6 offscreen 在窗口 show 时合成 Enter 事件**（即使指针不在锚上，offscreen 假光标在 8,8）→ host 的 Enter 处理加光标位置守卫。
- host 的 resizeEvent 会把 anchor 重置为 host 矩形——测试/调用方应设置 **host** 几何而非 anchor。
- `tooltip()` 原为惰性创建，测试在 show 前访问返回 nullptr → 改为构造即建。
- Qt5/Qt6 差异：QTest::qWait(30) 在 Qt6 可能等不到 16ms 定时器的首个 tick（用 60ms）；clearFocus 后 setFocus(reason) 才会重发 FocusIn（已聚焦的 widget setFocus 不重发事件）。
- MutatorMutex 模式陷阱：`globalShowingHost()->dismiss()` 会清空静态指针，随后再 `->finishLeaving()` 是空指针解引用——先取局部副本。

**画廊页教训**：build() 重入时未 bank 的控件（MdButton）会生成孤儿叠在原点——所有控件创建必须走 bank。
