## Card —— §1.4 Containment 首族（14/36）

提交 `7495efc`，直连推送 main+dev，memory 本条同批。

**移植源**：material-web **没有 card 网页组件**（根目录无 card 包，与 Tooltip/Loading 同款「仅 token 导出」局面——memory 里上一条写「material-web 有组件源码」是错的，实际三份导出 `_md-comp-{filled,elevated,outlined}-card.scss`（34.0.21）+ 行为源 Compose M3 Card.kt（931 行）。

**关键 token/行为事实**：
- 三变体共享 corner-medium + on-surface 状态层；差异在容器色与海拔阶梯：filled = surface-container-highest 静置 L0（hover L1、dragged L3）；elevated = surface-container-low 静置 L1（hover L2、dragged L4）；outlined = surface + 1px outline-variant（focus 转 on-surface）。
- **按压不高抬**——"Pressed (ripple)" 行重复静置海拔，按压响应就是涟漪（与按钮族同规则）。
- 导出**有**禁用行（与 FAB 不同）：filled→surface-variant、elevated→surface、outlined 容器不变；Compose 合成算术 0.38 容器 / 0.38 内容 / 0.12 描边，**叠加在启用容器色之上**。
- Compose 每变体只有两种形态：非点击（无交互源、状态表停启用行、禁用色不生效）与可点击——移植为一个 widget 的 `clickable` 开关。
- 海拔**动画**（Compose 走主题 motion scheme）：本移植 200ms 标准缓动 tween（登记分歧）、禁用瞬跳；`MdElevation::drawShadowDp` 新重载供动画 dp 绘制。
- contentColorFor(surface*) = OnSurface（无独立 token 行）。

**新文件**：`MdCardTokens/Style/Card` 三层 + `TestMd3Card`（16 检查项）+ `GalleryPages21`（页 21）。MdCard 是 Pattern A **容器**：children 走 contents margins 填满容器（clickable 留焦点边距、非 clickable 零边距），无默认内容边距（Compose 同）。

**坑**：
- `QRect::contains(QPointF)` Qt5 没有（用 toPoint()）；`drawShadow` 是 level 枚举签名，动画需 dp 重载。
- **NoQss 门禁连画廊 QLabel 的 setStyleSheet 都抓**——标题加粗改用 QFont::setBold。
- 焦点测试：activateWindow() 已以 ActiveWindowFocusReason 给焦，随后 setFocus(Tab) 不重发 FocusIn——先 clearFocus + qWait 再请求（Tooltip 坑再现）。
- plainKeys(component, token) 是两参；key 形如 `md.comp.filled-card.container.shape`。

**进度**：**14/36**。下一族：§1.4 剩余 Dialogs、Bottom sheets。
