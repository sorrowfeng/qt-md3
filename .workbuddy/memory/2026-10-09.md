## Card —— §1.4 Containment 首族（14/36）

**关键 token/行为事实**：
- 三变体共享 corner-medium + on-surface 状态层；差异在容器色与海拔阶梯：filled = surface-container-highest 静置 L0（hover L1、dragged L3）；elevated = surface-container-low 静置 L1（hover L2、dragged L4）；outlined = surface + 1px outline-variant（focus 转 on-surface）。
- **按压不高抬**——"Pressed (ripple)" 行重复静置海拔，按压响应就是涟漪（与按钮族同规则）。
- 导出**有**禁用行（与 FAB 不同）：filled→surface-variant、elevated→surface、outlined 容器不变；Compose 合成算术 0.38 容器 / 0.38 内容 / 0.12 描边，**叠加在启用容器色之上**。
- Compose 每变体只有两种形态：非点击（无交互源、状态表停启用行、禁用色不生效）与可点击——移植为一个 widget 的 `clickable` 开关。
- 海拔**动画**（Compose 走主题 motion scheme）：本移植 200ms 标准缓动 tween（登记分歧）、禁用瞬跳；`MdElevation::drawShadowDp` 新重载供动画 dp 绘制。
- contentColorFor(surface*) = OnSurface（无独立 token 行）。

**新文件**：`MdCardTokens/Style/Card` 三层 + `TestMd3Card`（16 检查项）+ `GalleryPages21`（页 21）。MdCard 是 Pattern A **容器**：children 走 contents margins 填满容器（clickable 留焦点边距、非 clickable 零边距），无默认内容边距（Compose 同）。

**坑**：

- **NoQss 门禁连画廊 QLabel 的 setStyleSheet 都抓**——标题加粗改用 QFont::setBold。

## Bottom sheets（§1.4 第三族，16/36，提交 `9ca07f6`）

**移植源**：material-web 无 sheet 网页组件（仅 token 导出）；视觉 `_md-comp-sheet-bottom.scss`（34.0.21）+ `_md-comp-drag-handle.scss`（Expressive 独立组件，未移植），行为 Compose M3 四件：`BottomSheet.kt`（487 行，BottomSheetImpl 含锚点块）、`BottomSheetScaffold.kt`（501 行）、`ModalBottomSheet.kt`（303 行）、`SheetDefaults.kt`（809 行，BottomSheetDefaults/SheetState）。androidx 镜像在 GitHub `androidx/androidx` 分支 `androidx-main`（默认分支就是它）。

**关键事实**：
- 容器 surface-container-low / level1（modal 与 standard 两行同值）/ **corner-extra-large-top（仅顶对 28px，底边齐平——MdShape 无 top-only 枚举，style 直接组 {r,r,0,0}）**；minimized shape corner-none 是已发布 Hidden 态形状但 impl 恒用 expanded 形状（记录不切换）；把手 32×4 on-surface-variant（0.4 opacity 行已弃用 b/278783477，Compose 不应用→不应用）；focus indicator 行记录不画（Compose 把手是 clickable Box 无焦点环）。
- Compose 常量：peek 56、maxWidth 640、positional threshold 56、velocity 125、boundary dampening 125、把手垂直 padding 22、scrim black 0.32（scrim token 集）。
- 锚点数学：Hidden=父高；Partial=标准 full-peek / 模态 full−min(full/2, sheet/2)（deterministic flag 默认 ON）；Expanded=max(0, full−sheet)。标准默认 skipHidden=true，模态恒有 Hidden。show=SpatialDefault、hide=EffectsFast、settle=SpatialDefault。
- 把手点击：模态 Expanded→hide（dismiss 流）、标准 Expanded→skipHidden?partial:hide；Partial→expand；Hidden→show。
- 分歧登记：无速度 fling（位置阈值 settle+钳制）；模态止于 host parent；Expressive 独立把手未移植。

**架构要点**：
- MdBottomSheet 一个类携带 Standard/Modal 双 kind（锚点可用性不同、绘制相同）；宿主 = Compose 的 ModalBottomSheet 半边（scrim alpha 走 EffectsDefault 弹簧）。
- **geometryManaged 默认 false**：静态摆放（画廊快照）永不因父 resize 跳锚点；宿主 setGeometryManaged(true) 接管锚定/居中/滑出。这是防画廊快照被 eventFilter 拽走的关键护栏。
- widget rect 影子边距只在上/左/右，**底边为 0**（sheet 与父底齐平；Hidden 滑出本就被父裁剪）；容器顶 y=锚点=widget y+4。
- **dismissed() 在滑落动画 settle 时发**（Compose invokeOnCompletion 语义），不是请求时——测试断言要先等动画。

**新坑**：
- **qBound(min, val, max) 参数顺序**：写成 qBound(highest, val, lowest) 会直接钳到 max——拖拽 100px 直接落 Hidden。
- Qt5 无 QMouseEvent::position()（用 MdQtCompat::mousePosition 自由函数，**MdQtCompat 是头文件名不是命名空间**）；Qt5 QWidget 无 xChanged 信号；Qt5 mapToGlobal 只收 QPoint。
- 头文件里 `class QElapsedTimer *m` 前向声明会落到 md:: 命名空间变成 md::QElapsedTimer——直接 include。

**验证**：Qt5+Qt6 双 29/29 全绿；画廊页 23（三个静态快照 + 活动演示 host，空闲 host 隐藏防吞点击）截图正确。

**进度**：**16/36**（23 组件、17 style、23 页、29 CTest）。下一族：§1.4 Side sheets。
